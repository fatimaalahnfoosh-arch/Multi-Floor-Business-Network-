# Multi-Floor Business Network

A network design and configuration project for a small multi-floor organization, implemented using Cisco Packet Tracer.

## Overview
The project provides a reliable and scalable network that connects multiple departments across different floors while supporting wired and wireless communication.

## Features
- LAN design and configuration
- VLANs and Inter-VLAN Routing
- IP Addressing and Subnetting
- DHCP and DNS Services
- Web Server
- Wireless Access Points
- VoIP Communication
- Router and Switch Configuration
- Network Connectivity Testing

## Technologies Used
- Cisco Packet Tracer
- Routers and Switches
- VLANs
- DHCP
- DNS
- VoIP
- Wireless Networking

## Project Type
Computer Networks Project
